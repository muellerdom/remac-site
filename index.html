Getting started

  1. Install ReMac on the Mac you want to use as a TV (download above, once available). It lives in the menu bar, or full screen in TV mode.
  2. Allow Accessibility access when ReMac asks, so the remote can move the pointer and type. The Welcome to ReMac window that opens on first launch has a button for it.
  3. Install ReMac Remote on your iPhone from the App Store.
  4. On the Mac, choose Pair iPhone… in the ReMac menu or the welcome window, and scan the code with the iPhone. Check that both show the same six-digit code, then click Allow on the Mac.

Common questions

The iPhone doesn't find my Mac

Both must be on the same network, ReMac must be running, and the Mac must be awake. If the Mac sleeps, set it to stay awake while its display is off, or turn on "Wake for network access" in System Settings.

The Mac stays dark

Press any button on the remote: the first press wakes the screen and ends the screen saver. Opening an app or pressing Power wakes the screen and carries on. If the Mac is locked, unlock it at the Mac; ReMac never handles your password.

Which browsers work for web tiles?

Brave, Vivaldi, Edge, Chrome, Opera, Firefox and Safari. Brave is recommended: tiles open in their own private profile and videos switch to full screen automatically. In Safari, videos don't switch to full screen on their own.

Switching VPN locations

ReMac switches VPN services you have already set up on the Mac. In ReMac Settings › VPN, "Set Up VPN…" walks you through it. Respect the terms of the services you watch.
